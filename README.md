# MindBloom - Mental Wellness Tracker

MindBloom is a hackathon-ready mental wellness app for students preparing for JEE, NEET, CUET, CAT, GATE, UPSC, and board exams.  
It helps students track mood and stress, identify triggers, reflect daily, and receive personalized support.

## Features

- Pixar-style calming UI (soft gradients, rounded cards, animated buddy)
- Fast daily check-in (mood, stress, energy, sleep, triggers, note, reflection)
- Trigger analysis and weekly mood trend
- Rule-based burnout risk and support recommendations
- Local-first data storage for instant MVP use
- Unit, component, and e2e tests

## Tech Stack

- Next.js 16 + TypeScript + App Router
- Tailwind CSS 4
- Framer Motion
- Vitest + Testing Library
- Playwright

## Run Locally

```bash
npm install
npm run dev
```

App URL: `http://localhost:3000`

## Test Commands

```bash
npm run lint
npm run test:run
npm run test:e2e
```
